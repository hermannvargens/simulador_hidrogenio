# Simulador de Condicionamento de H2

Aplicativo Streamlit para simulação termodinâmica e exergética de um sistema de condicionamento de Hidrogênio (H2).

## Como rodar localmente

1. Instale as dependências:
```bash
pip install -r requirements.txt
```
2. Execute o aplicativo:
```bash
streamlit run app.py
```

Certifique-se de adicionar o arquivo `Leachman.py` (fornecido em aula) na mesma pasta antes de executar.
